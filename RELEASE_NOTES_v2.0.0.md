# Release v2.0.0

This release corresponds to the substantially expanded reproducibility package for the manuscript **Beyond Rescheduling: Human-Centric Governance and LLM Explanation Support for Manufacturing Disruption Recovery in Industry 5.0**.

The operational selector is deterministic; the LLM is downstream and explanation-only. The release contains the paired synthetic and benchmark-derived datasets/results, statistical tests, sensitivity analyses, exact LLM system prompt and JSON schema, archived explanation metrics, and numerical manuscript-verification file.
