# Changelog

## v2.0.0 — manuscript reproducibility release

- separates deterministic operational recovery selection from LLM explanation;
- adds capability-checked bypass, degraded mode, repair-wait, and reschedule-only evaluation under common disrupted states;
- adds five transparent comparator policies;
- adds FT06, LA01, and LA06 benchmark-derived disruption experiments;
- adds paired confidence intervals, hypothesis tests, effect sizes, and FDR correction;
- adds weight, threshold, and proxy-coefficient sensitivity analyses;
- adds deterministic-template versus constrained-LLM explanation evaluation;
- archives the completed 60-call LLM metrics and sanitized call records;
- removes the previous illustrative scenario workflow and any human-study preparation artifacts.
